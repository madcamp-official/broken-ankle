## 🎨 3. 픽셀 스펙

| 항목 | 값 | 상태 |
| --- | --- | --- |
| 타일 크기 | 32×32 px 권장 | 🟡 |
| **PPU** | **32** | ✅ |
| Unity 월드 타일 크기 | 1 × 1 units | 계산값 |
| 캐릭터 스프라이트 | 32×32 px | 🟡 |
| 기준 해상도 | 640×360 | 🟡 |
| Camera Orthographic Size | 5.625 | 계산값 |
| 화면 표시 범위 | 20 × 11.25 칸 (20 × 11.25 units) | 계산값 |
| Pixel Snapping | 켬 | 🟡 |
| Upscale Render Texture | 양쪽 테스트 후 결정 | ⬜ |

> PPU 32 고정이라면 메인 타일 규격은 32×32 px를 권장합니다. 이렇게 하면 타일 1칸이 Unity 월드에서 1유닛이 되어 Tilemap, 이동 거리, 충돌 크기, 카메라 계산이 가장 단순해집니다. 기존처럼 화면에 20×11.25칸을 보이게 하려면 기준 해상도는 640×360으로 잡습니다.
>
> 16×16 에셋도 사용할 수는 있지만, PPU 32에서는 타일 1칸이 0.5유닛이 됩니다. 초보 개발에서는 Grid Cell Size 0.5, 이동 단위 0.5, 충돌 크기 0.5를 계속 맞춰야 해서 실수가 늘어날 수 있습니다. 16×16 에셋은 프로토타입, 작은 소품, 또는 2배 업스케일 후 보조 에셋으로 쓰는 쪽이 안전합니다.

### 비주얼 퀄리티는 여기서 올립니다

- 조명 해상도 분리 (Upscale Render Texture 끄기)
- 애니메이션 프레임 추가 (4 → 6프레임)
- 포스트프로세싱 (그레인, 비네팅, 색수차, 스캔라인)
- 팔레트 통일

## ⚙️ 4. 스프라이트 임포트 설정

| 항목 | 값 |
| --- | --- |
| Sprite Mode | Multiple |
| Pixels Per Unit | 32 |
| Filter Mode | **Point (no filter)** |
| Compression | **None** |
| Mesh Type | Full Rect |
| Generate Mip Maps | 끔 |
| Pivot | 캐릭터 Bottom / 타일 Center |
| Slice | Grid By Cell Size |

> ⚠️ 16×16 타일셋을 그대로 PPU 32로 임포트하면 타일 하나의 월드 크기는 0.5유닛입니다. 메인 Tilemap은 32×32 타일 기준을 우선하고, 16×16 에셋을 섞을 때만 의도적으로 0.5유닛 소품/디테일로 취급하세요.
>
> ⚠️ Sprite Atlas를 쓸 경우 **아틀라스 설정이 개별 스프라이트 설정을 덮어씁니다.** 아틀라스에도 Point / None을 동일하게 적용하세요.

## ✏️ 6. 직접 제작 대상

| 항목 | 물량 |
| --- | --- |
| 플레이어 캐릭터 2종 | 4방향 × 4프레임 = 32프레임 |
| 정숙 관리자 (몬스터) | 4방향 × 2~3프레임 |
| 상호작용 오브젝트 5종 | 배전반, 서버랙, 확성기, 세탁기, 전화기 |
| 덧그릴 소품 | 낙서, 물때, 균열 등 오버레이 |

**총 60~80프레임 목표.** 나머지는 기성 팩 + 팔레트 재도색으로 해결합니다.

### 스프라이트 시트 규칙

- 가로 = 프레임 (4프레임)
- 세로 = 방향 (**down → up → left → right 순서 고정**)
- 결과: 64×96 PNG
- 배경 투명 유지, 스케일 1배

> ⚠️ 방향 순서를 나중에 바꾸면 유니티 슬라이스 인덱스가 전부 어긋납니다.
> 

### 폴더 구조

```

  /ArtSource          ← .pxo 원본 (유니티 밖)
    /characters
    /tiles
    /props
  /UnityProject
    /Assets
      /Art            ← 내보낸 PNG만
```

## 🔊 7. 오디오 방침

**이 게임은 그래픽보다 오디오가 본체입니다.** 에셋 조달 시간을 오디오에 우선 배분합니다.

### 확보할 카테고리

- 산업용 앰비언스 (보일러실, 환풍기, 배전반 험)
- 형광등 점멸 · 명멸음
- 금속 문, 철제 계단, 콘크리트 발소리
- **무선 잡음, 테이프 히스, 라디오 스태틱** ← 시그니처 질감
- 오래된 가전 (냉장고 컴프레서, 세탁기)
- 종이, 스위치, 레버, 기계식 조작음

### 직접 제작

- 헬멧 안의 젖은 숨소리
- 벽을 두드리는 소리
- 안내방송 (AI 음성 합성 → 저품질 스피커 가공)

> 💡 이 게임의 미학은 “열화된 오래된 녹음”입니다. **음질이 나쁠수록 오히려 맞습니다.**
