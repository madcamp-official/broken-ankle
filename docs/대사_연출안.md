# 대사/연출안

`docs/와이어프레임.txt`, `docs/스토리(애슈번).md`, `docs/기믹.txt` 기준으로 정리한 진행용 대사와 컷신 연출안이다.

## 0. 사용 방식

각 이벤트는 아래 구조로 옮기기 좋게 적었다.

| 항목 | 의미 |
|---|---|
| ID | DialogueData 또는 Timeline Signal 이름 |
| 조건 | 트리거 조건 |
| 조작 | 플레이어 입력 처리 |
| 연출 | 카메라, 조명, 사운드, 몬스터 동작 |
| 대사 | 화면 하단 대사창에 표시할 문장 |

권장 톤은 "둘은 전문 기술자라서 처음에는 침착하지만, 장소가 넘어갈수록 회사 지시보다 서로의 판단을 믿게 되는 흐름"이다.

## 1. 시작 TV

### `intro_tv_001`

조건: 시작 버튼 클릭  
조작: 입력 잠금  
연출: 검은 화면에서 CRT 노이즈. TV 화면만 먼저 보이고, 센틸 로고가 1초 늦게 점등된다. 화면 가장자리는 휘고, 자막은 가끔 한 글자씩 밀린다.

대사:

| 화자 | 내용 |
|---|---|
| 센틸 안내방송 | 애슈번 복구 사전 조사 임무에 배정된 것을 환영합니다. |
| 센틸 안내방송 | 애슈번은 약 20년 전 발생한 화재 및 유독가스 사고 이후 폐쇄된 주거단지입니다. |
| 센틸 안내방송 | 귀하는 철거 전 남아 있는 마을 데이터를 회수하고, 주요 시설 전력을 확인해야 합니다. |
| 센틸 안내방송 | 현장 내부에는 잔류 저주파와 비정상 음향 반사가 존재할 수 있습니다. 지급된 헤드셋을 반드시 착용하십시오. |
| 센틸 안내방송 | 헤드셋은 손전등, 음향 방향 표시, 근거리 노이즈 상쇄 기능을 제공합니다. |
| 센틸 안내방송 | 동료 헤드셋에서 발생한 신호는 초록색으로 표시됩니다. 초록색 신호는 안전한 협업 신호입니다. |
| 센틸 안내방송 | 불필요한 대화, 고성, 장비 타격음은 현장 안전을 위해 삼가십시오. |
| 센틸 안내방송 | 더 나은 내일을 위한 더 나은 집. 센틸이 함께합니다. |

추가 연출:

| 타이밍 | 내용 |
|---|---|
| "초록색" 설명 | 화면 속 "초록색" 단어만 초록색으로 깜빡임 |
| 마지막 문장 | TV 화면이 순간적으로 주민 구조 요청 자막으로 바뀌었다가 복구됨 |
| 종료 | TV에서 줌아웃해 Container Box 씬으로 전환 |

## 11. 구현 메모

| 기능 | 적용 방식 |
|---|---|
| 대사 중 입력 잠금 | `DialogueTrigger`가 시작 시 PlayerController 입력 비활성, 종료 시 복구 |
| 자동으로 넘어가는 대사 | `DialogueManager.TryPlay(autoAdvanceSeconds:)`. 회사 도주(`corp_escape_001`)처럼 플레이어를 태우고 가는 구간에 쓴다. 눌러도 바로 넘어간다 |
| 플래그로 시작하는 대사 | `FlaggedDialogue`. 바닥의 선을 밟는 대신 세상이 그렇게 된 순간에 재생된다 |
| 두 사람이 각자 끝내는 조건 | `WorldFlagAll` 이 여러 플래그를 모아 결과 플래그 하나를 올린다 |
| 역할 제한 | `Required Slot`. `-1` 누구든, `0` 네이선, `1` 그랜트 |
| 자동 도주 | Timeline 또는 코루틴으로 두 캐릭터 waypoint 이동 |
| 몬스터 반응 | 대사 이벤트 시작/종료 시 가짜 NoiseSource를 생성해 MonsterAI가 듣게 함 |
| TV/스크린 | UI Canvas 또는 별도 씬 카메라 RenderTexture 사용 |
| 초록색 강조 | TextMeshPro rich text `<color=#54ff7a>` 사용 |
| 문서 조건 | `WorldState`에 `HasReadNoiseSystemDoc`, `ElevatorFixed`, `HangarPowerFixed`, `HasReadWardenDoc` 같은 bool 저장 |
| 재생 중복 방지 | 각 이벤트 ID를 `WorldState`에 완료 플래그로 저장 |
